# 미정 사항

이 문서는 현재 비어 있는 설계 영역을 보여 줍니다. 지금 모두 답해야 하는 질문 목록은 아닙니다.
사용자가 관련 아이디어를 전달하면 알맞은 기획 문서로 옮기고 여기에는 결과와 참조를 남깁니다.

| 항목 | 현재 상태 | 이후 처리 |
| --- | --- | --- |
| 핵심 플레이 경험 | 아직 전달받은 기획 없음 | 관련 아이디어가 생기면 경험과 목표를 기록 |
| 세계관·서사·캐릭터 | 아직 전달받은 기획 없음 | 실제 내용에 따라 문서를 분리 |
| 전투·성장·탐험 등 규칙 | 아직 전달받은 기획 없음 | 필요하다고 확인된 시스템만 작성 |
| 아이템·스탯 | 분류·접두어의 명시 규칙과 구조 추론안 기록 | 아래 미정 사항을 후속 입력에 따라 해소 |
| 조작감·액션 | 추론 요청은 있으나 구체적 경험·효과는 아직 없음 | 실제 아이디어에서 행동 조건과 타이밍을 유추 |
| 게임 엔진 | 명시적으로 미정 | 현재 기획 작업의 전제로 삼지 않음 |
| 아트스타일 | 명시적으로 미정 | 특정 표현 방식을 가정하지 않음 |
| 세부 구현 | 명시적으로 미정 | 기획에서 필요한 조건과 결과만 설명 |

## 아이템·스탯의 열린 질문

확정 규칙은 [SPEC-0001](design/items/classification-and-prefixes.md), 제안과 그 근거는 [SPEC-0002](design/items/item-stat-inference.md)를 참조합니다.

| 질문 | 현재 정리 |
| --- | --- |
| 접두어가 어떤 스탯을 어떤 식으로 바꾸는가? | 대상·보정량·고정값 또는 비율·반올림 등 미정 |
| 긍정·부정은 수치 증감인가, 유불리 기준인가? | 음수와 작을수록 좋은 스탯을 처리하려면 구분 필요 |
| 기본값도 음수일 수 있는가? | 아이템 스탯의 음수 허용은 명시됨. 발생 경로와 캐릭터 최종 스탯 범위는 미정 |
| 도감 번호는 아이템 종류마다 고유한가? | 종류별 번호, 개체 간 공유 구조를 제안했으나 미확정 |
| 도감 등록 시점과 수집 단위는 무엇인가? | 기본 아이템별 기록을 제안. 접두어별 수집·계정 또는 캐릭터 귀속은 미정 |
| 재드롭·재판매·다른 획득 경로는 어떻게 처리하는가? | 최초 획득과 구분할 필요가 있으며 아직 규칙 없음 |
| 적용 가능한 접두어나 스탯이 없는 경우는? | 적용 예외와 후보 선택 규칙 미정 |

현재 기록된 확정 기획 사이에 확인된 충돌은 없습니다. 추론안은 사용자 승인과 구분합니다.
